Quick Start

Install once, then point your agent at any of the 22 servers

1

Install

one-time

Python 3.12+ and pipx. One package installs all 22 servers.

Reopen the terminal if ensurepath changes your PATH. If pipx picks an older Python, add the --python 3.12 flag.

2

Verify

before you connect

Confirm 22 servers before you wire up a client. doctor exits non-zero if one is missing.

Run nepa-mcp list-servers for the full table. The amber lines are optional keys — add them below, or skip them.

Instead of step 3

Codex Desktop plugin

One install for all 22 servers and the screening skill

GitHub marketplace

The repository is itself a GitHub-hosted plugin marketplace. One install registers all 22 servers and the nepa-screening skill, which tells the agent how to establish a project area and pick the right datasets.

  • All 22 servers at once, with no per-server entries
  • Bundles the screening skill and starter prompts
  • Adds from GitHub, no clone required

In Codex Desktop, after pipx install nepa-mcp:

  1. 1

    Open Plugins and select Add plugin marketplace.

  2. 2

    Enter pnnl/nepa-mcp for Source and v0.1.5 for Git ref.

    Source pnnl/nepa-mcp
    Git ref v0.1.5
  3. 3

    Add the marketplace, then install NEPA-MCP.

    NEPA-MCP 22 servers · nepa-screening skill Installed

Start a new Codex task after installing or updating the plugin so the tools and skill are loaded.

If you install the plugin, do not also run nepa-mcp configure codex. No Desktop app? The README has the equivalent codex plugin commands.
