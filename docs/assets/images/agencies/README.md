# Source agency marks

Retrieved on 7 September 2026 for attribution of the toolkit's upstream public data sources. The marks identify their respective organizations; they do not imply endorsement or partnership with the toolkit.

Assets are served locally. NOAA and National Archives PNGs were proportionally resized for the gallery. The USGS and DOT source assets are white; CSS renders their existing silhouettes in dark ink on the site's white background. Other marks retain their original colors. The USDA symbol is the mark displayed on the NRCS website. The National Archives mark accompanies the combined NARA / GPO source family.

SVG line endings and trailing whitespace are normalized; the artwork's geometry is preserved.

`dot-symbol.svg` uses the left 56 × 50 portion of the original DOT header lockup. Only the viewBox is changed; the emblem's original path geometry is preserved. `dot.svg` retains the complete source lockup for provenance.
