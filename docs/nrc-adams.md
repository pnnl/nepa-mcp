# NRC ADAMS document research

Six read-only tools support scoped search, accession metadata, bounded indexed text, explicit package membership, original PDF resources, and evidence-located reference candidates. The local stdio server uses the documented [NRC APS subscription API](https://adams-api-developer.nrc.gov/) and [APS API guide v1.0](https://adams-search.nrc.gov/assets/APS-API-Guide.pdf). The anonymous website backend is not a fallback or an asserted equivalent contract.

## Secure subscription setup

1. Register/sign in through the NRC developer portal, verify the account, and use its Products/Subscriptions interface for the ADAMS Public Search API. Follow the current portal requirements; no price, quota, or activation time is assumed here.
2. Run `nepa-mcp configure credentials` to create the owner-only per-user file. On macOS the default is `~/Library/Application Support/nepa-mcp/credentials.env`; `NEPA_MCP_CONFIG_FILE` can select another private file. Add `NRC_ADAMS_API_KEY=<your local value>` directly in that file, outside chat. Existing files are deliberately not overwritten: add the new variable yourself and keep file permissions at 0600. The parent is created at 0700 when new.
3. Process environment values take precedence. `nepa-mcp doctor` reports only whether credentials are configured, plus the requirement for the selected NRC adapter. Restart the server after changes. Missing configuration affects dependent calls, not discovery or unrelated servers.

The registry-derived credential allowlist, loader, private template, and secret-free diagnostics/configuration are integrated together. Client/plugin JSON/TOML contains no subscription value. The subscription header is sent only to `https://adams-api.nrc.gov/aps/api/search` and its validated accession route. API redirects are refused; PDF downloads use separate requests without subscription headers and validate every redirect. Exceptions/response bodies are not echoed. Do not paste keys into chat, fixtures, repository files, URLs, or tool arguments. Rotate at NRC if a key is exposed. The existing toolkit runtime loads the full registry allowlist into process environment; this integration does not claim per-server process secret isolation.

## Evidence and bounds

- Search submits typed AND filters and documented `skip` continuation. It bounds local output to 1–100 records and does not invent `pageSize`/`page`. Exact published numeric docket strings retain leading zeros; alternate punctuation is rejected instead of guessed. Document types are exact source values. Date comparisons follow documented YYYY-MM-DD ge/le semantics; source timestamps can have ambiguous time zones. Main/legacy/both library scopes and source counts are explicit. Index changes can alter consecutive requests.
- API JSON is streamed up to 8 MiB, independently of text chunks (1–20,000 characters). Oversized JSON is rejected whole. Indexed text is labelled as such, fingerprinted, and never claimed to be a complete original. Base64 is decoded only when an explicit supported encoding is declared. Metadata-only legacy records, absent/empty text, encoding failures, and source failures differ.
- Packages use outgoing `DocumentsFiledInPackage` only, preserve parent `PackagesFiledIn`, deduplicate identities, keep nested packages, identify self cycles, and resolve at most ten members per output page without recursion. Missing membership fields are unknown, not empty packages. The guide has no nonempty authenticated membership fixture; that validation remains pending.
- Original PDF streams default to 10 MiB, configurable up to 25 MiB. MIME/signature, every redirect, actual byte count, SHA-256, and bounded isolated parser output are checked. No caller URL is accepted. HTML/challenge pages and oversized/unavailable originals do not create snapshots. Resources live in an in-process immutable store (50 MiB total, 15-minute expiry, eviction/server restart possible). Resource reads verify the hash and never fetch replacement bytes silently.
- Reference extraction scans at most 1,000,000 indexed characters or 500 PDF pages, with a 1,000,000-character PDF extraction budget and 15-second isolated parser limit. No OCR. It reports source extent, image-only pages, self/duplicate mentions, evidence snippets, physical PDF pages or indexed character offsets, and independent candidate pagination. Numeric legacy candidates need explicit ADAMS link context. At most ten target metadata lookups are optional. Compare the representation fingerprint when resuming; mentions do not establish support or package relationships.

## Verification status

Offline tests validate the implemented guide contract, missing-key behavior, query validation, credential loading/redaction, rate limits, malformed/oversized responses, package direction/cycles, PDF caps/redirects/expiry/resource links, and source-located references. Synthetic package/PDF fixtures are test cases, not authenticated NRC captures. Guide and public website observations informed development; they do not certify API schema parity. A no-key request to the supported API returned HTTP 401 on October 23, 2026.

Before declaring the integration functional, configure an authorized subscription and verify authenticated search/skip/filter behavior, a document, a nonempty package and membership direction, a multi-docket record, a legacy/bibliographic record, and text encoding/completeness. Verify original-file access independently, including a genuine outgoing-reference case and self-only negative case. Document current quotas from the subscription; do not infer them from 401 or public-web success. No authenticated live request was made in this preparation.
