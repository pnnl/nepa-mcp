Permitting Coverage

Today the toolkit answers NEPA questions, at the federal level, for energy infrastructure. That is one cell. Every tool takes a region of interest and returns cited records, so the same interface applies to other statutes, other jurisdictions, and other project types.

→Statutory framework

A project rarely triggers NEPA alone. ESA, NHPA, the Clean Water Act, and the Clean Air Act often apply to the same project at the same time.

↑Jurisdiction

Federal sources are covered today. States, Tribes, and regional bodies publish their own datasets, and a review has to account for those too.

↗Project sector

Minerals and mining, geothermal, and hydropower each draw on datasets that an energy infrastructure review would not need.

The toolkit already covers 19 servers across 12 federal agencies. Each new dataset is a new adapter behind the same interface, and the code is public, so a state agency or research group can add its own data and contribute it back.
