→Statutory framework

Selected servers return project-area records that may inform aspects of screening under ESA §7, NHPA §106, CWA §404, Clean Air Act New Source Review, and FLPMA.

↑Jurisdiction

Federal sources are covered today. States, Tribes, and regional bodies publish their own datasets, and a review has to account for those too.

↗Project sector

Minerals and mining, geothermal, and hydropower each draw on datasets that an energy infrastructure review would not need.

The toolkit already covers 21 servers across 13 federal agencies. Each new dataset is a new adapter behind the same interface, and the code is public, so a state agency or research group can add its own data and contribute it back.
